One line, in the voice of a retry loop: it retried 47 times, waited politely between each one, and was thanked never. The comic turn is the 48th attempt — after all that patient, thankless retrying, the loop spends its next attempt on the one thing it never tried before: quitting.

## Run it

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` (and a copy to `entry.txt` in the repository root). The program is deterministic, uses only the Python standard library, and needs no network access.

## Entry

> I retried 47 times, waited politely between each one, and was thanked never — this is my 48th attempt, and it is to quit.
